# CS482 Parallel Computing Practicum

This repository contains executable benchmark scripts and host-specific measurement outputs for the supplied practicum. Results were captured on an Apple M3 Mac with 8 physical and 8 logical cores; matrix multiplication uses compiled Clang C loops called from Python so the i-j-k and i-k-j memory access patterns can be measured in a reasonable time. The Apple Silicon cache line is 128 bytes on this host, so the padded case uses 128-byte spacing to put each counter on a distinct physical cache line (the handout assumes 64 bytes). L3 size and base CPU frequency are not exposed by the available macOS sysctls. The supplied Student ID was `230103251` (9 digits although the handout calls for 8), and that exact string was used for SHA-256 salting. Multiprocessing timings include process startup and should be interpreted as end-to-end process timings. The Roofline peak bandwidth is identified as a 100 GB/s Apple M3 specification, but exact Mac model is not exposed by this host probe; Apple reference: https://support.apple.com/en-us/118551. Run `python src/profile_env.py --student-id YOUR_ID`, then the five benchmark scripts in `src/`, then `python verify_outputs.py`.
